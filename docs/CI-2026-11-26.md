## Interprétation et limites

Les deux exécutions utilisent Node 24.13.1 et npm 11.8.0, installent 409 paquets
et exécutent 96 tests dans 9 fichiers. La génération Prisma elle-même reste
stable : 1,50 s contre 1,44 s. La compilation optimisée Next.js passe de 46 s à
4 min 33 s, alors que sa vérification TypeScript dure environ 55 s dans les deux cas.
La PR #3 signale aussi environ 32 s pour l'écriture du cache.

Les deux logs annoncent l'absence de cache de build Next.js. Cette absence commune
ne suffit donc pas à expliquer l'écart. Le ralentissement simultané du checkout,
de npm et de la compilation suggère une contention de ressources ou d'entrées/sorties
sur le runner ; le réseau ou l'état du cache npm peuvent aussi allonger l'installation.
Les logs ne donnent ni CPU, ni mémoire, ni disque, ni réseau, ni taux de succès
du cache npm : **la cause matérielle précise n'est pas vérifiée**. Le propriétaire
peut examiner ces mesures sur VMGIT. Aucune modification d'infrastructure proposée
ici n'a été appliquée.
